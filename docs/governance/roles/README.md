# Velox Committee Roles

These role documents turn the Velox governance committee into first-class platform artifacts.

They are meant to be read by:

- humans reviewing how Velox should be governed
- AI agents contributing to Velox design and development
- future platform features that need a canonical governance reference

The machine-readable registry for these roles lives in:

- [config/governance_committee.json](../../../config/governance_committee.json)
